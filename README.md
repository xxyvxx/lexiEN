# Лэкси EN

Учебный тренажёр английского для школьников (5–9 класс): теория, уровни, практика и профиль.

**Сайт:** [https://xxyvxx.github.io/lexiEN/](https://xxyvxx.github.io/lexiEN/index.html)

## Демо-вход

| Логин   | Пароль | Что внутри        |
|---------|--------|-------------------|
| `admin` | `1234` | пустой профиль    |
| `demo`  | `1234` | с прогрессом      |

Без входа доступна только **теория**. Тренажёр — после входа или регистрации.

## Разделы

- **Теория** — темы и короткий тест  
- **Тренажёр** — путь по уровням и практика (ошибки, слова, подбор, на слух, рассказы)  
- **Профиль** — прогресс, подсказки, личный словарь  

## Технологии

HTML, CSS, JavaScript (без фреймворков). Прогресс в `localStorage` браузера.

## Функциональность

### Главная и доступ
- Короткое знакомство с проектом и переходы в теорию, тренажёр и профиль.
- Без входа открыта только **теория**.
- Тренажёр и практика — после входа или регистрации; прогресс хранится в браузере.
- 
### Теория
- Список тем школьной грамматики (Present Simple, To be, There is/are и др.).
- Страница темы: объяснения, примеры, слова; на телефоне оглавление «В этой теме» сворачивается и не мешает читать.
- Можно перейти к тесту по теме или сразу в тренажёр по этой же теме.
- Тест по теории с результатом (сдан / не сдан).

### Тренажёр — путь
- Карта уровней по темам: пройденные, текущий и закрытые уровни.
- При открытии страница сама прокручивается к теме, которую ученик проходит сейчас.
- Вкладки «Путь» / «Практика» закреплены при прокрутке.
- В уровнях разные типы заданий: перевод, ввод слова, выбор значения, составление предложения, пары слов, диалоги, финальный уровень темы.
- За верные ответы начисляется **XP**; подсказки можно купить за XP в профиле.
- Сложные слова можно отправить в **«Повторить»**; выученные на уроке слова попадают в **личный словарь**.
- Если задание дважды не вышло — оно уходит в раздел **«Ошибки»**.

### Тренажёр — практика
- **Ошибки** — повтор заданий, которые не получились; можно пройти тему или одно задание.
- **Повторить** — слова из уроков: тест и карточки; повторённые можно убрать в словарь.
- **Подбор** — пары EN ↔ RU на время.
- **Изучение слов** — наборы по уровням, карточки «знаю / учу».
- **На слух** — различение английских звуков.
- **Рассказы** — чтение по темам, слова и короткий тест.
- **Как на контрольной** — смешанный тест из прогресса (открывается, когда накопилось достаточно заданий).

### Профиль и словарь
- Регистрация, вход, редактирование данных и фото (пресеты-собаки или своё фото).
- Статистика: XP, серия дней, уроки, прогресс по курсу.
- **Мой словарь** — список выученных слов, статусы «ок» / «не пройдено», тест по словарю; ошибка в тесте помечает слово и добавляет его в «Ошибки».
- Подсказки: покупка пакетов за XP.
