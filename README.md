# Лэкси EN

Учебный тренажёр английского для школьников (5–9 класс): теория, уровни, практика и профиль.

**Сайт:** [https://xxyvxx.github.io/lexiEN/](https://xxyvxx.github.io/lexiEN/index.html)

## Демо-вход

| Логин   | Пароль | Что внутри        |
|---------|--------|-------------------|
| `admin` | `1234` | пустой профиль    |
| `demo`  | `1234` | с прогрессом      |

Без входа доступна только **теория**. Тренажёр — после входа или регистрации.

## Разделы

- **Теория** — темы и короткий тест  
- **Тренажёр** — путь по уровням и практика (ошибки, слова, подбор, на слух, рассказы)  
- **Профиль** — прогресс, подсказки, личный словарь  

## Технологии

HTML, CSS, JavaScript (без фреймворков). Прогресс в `localStorage` браузера.

## Ответы на вопросы

**Какие инструменты использовали?**  
Cursor — для разработки и правок кода.

**Сколько времени потратили?**  
Около полутора дней.

**Что проверили?**  
Альтернативные сценарии (вход, прогресс, словарь, ошибки, переходы) и адаптивность на разных экранах, в том числе с телефона.

**Что ещё улучшили бы?**  
Дизайн; добавила бы просмотр коротких видеофрагментов с субтитрами и более разнообразные задания в уровнях.
