# Лэкси EN

Учебный тренажёр английского для школьников (5–9 класс): теория, уровни по темам, практика и профиль с прогрессом.

Статический сайт (HTML / CSS / JS). Прогресс хранится в браузере (`localStorage`) — отдельный сервер не нужен.

## Демо-вход

| Логин   | Пароль | Что внутри                          |
|---------|--------|-------------------------------------|
| `admin` | `1234` | пустой профиль                      |
| `demo`  | `1234` | прогресс: уровни, словарь, ошибки   |

**Без входа** доступна только **теория**. Тренажёр и практика открываются после входа или регистрации.

## Как открыть

### Локально

Открой `index.html` в браузере **или** подними простой сервер из корня проекта:

```bash
# Python
python -m http.server 8000

# Node
npx serve .
```

Затем зайди на `http://localhost:8000`.

### GitHub Pages

1. Загрузи файлы в репозиторий (корень = корень сайта, рядом с `index.html`).
2. **Settings → Pages → Source:** Deploy from a branch → ветка `main`, папка `/ (root)`.
3. Сайт будет по адресу: `https://ВАШ_НИК.github.io/ИМЯ_РЕПО/`

## Что внутри

- **Теория** — темы с объяснениями и коротким тестом  
- **Тренажёр → Путь** — уровни по грамматике (Present Simple, To be, There is/are и др.)  
- **Тренажёр → Практика** — ошибки, повторение слов, подбор пар, изучение слов, на слух, рассказы, контрольная  
- **Профиль** — XP, прогресс, подсказки, личный словарь и тест по нему  

## Структура проекта

```
├── index.html          # главная
├── css/                # стили
├── js/                 # логика (в т.ч. storage.js — «бэк» в браузере)
├── assets/             # брендовая собака (лого, empty-states)
├── corgi_emotions/     # персонажи в заданиях
├── pug_emotions/
├── shepherd_emotions/
├── icon/               # иконки практики
├── theory/             # теория
├── trainer/            # тренажёр и практика
└── profile/            # вход, регистрация, профиль
```

## Технологии

- HTML5, CSS3, JavaScript (без фреймворков и сборки)
- `localStorage` для аккаунтов и прогресса
- Адаптивная вёрстка (телефон / планшет / десктоп)

## Заметки для проверяющих

- После первого входа под `demo` прогресс уже заполнен — удобно смотреть путь, словарь и практику.
- Данные привязаны к браузеру: сброс сайта / другой браузер = «чистый» старт (демо-аккаунты создадутся снова).
- Для сброса локальных данных: DevTools → Application → Local Storage → очистить ключи `lexi-*`.
